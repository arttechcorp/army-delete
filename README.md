# 군생활 삭제 버튼

입대일과 전역일을 넣으면 남은 복무 기간을 보여주고, 커다란 버튼을 누르면 기분 좋은 소리가 나는 단일 페이지 웹 장난감입니다.

**아무것도 실제로 삭제되지 않습니다.**

## 기능

- 입대일 / 전역일 입력 → 진행률(%), 남은 개월·일, D-day, 복무 일수
- 군별 전역일 자동 계산 (육군·해병 18 / 해군 20 / 공군 21개월)
- 삭제 버튼 — 누를 때마다 Web Audio로 합성한 타격음, 연타하면 음이 올라가는 콤보
- 누적 클릭 수 · 입력값 · 음소거 설정을 브라우저에 저장 (`localStorage`, 외부 전송 없음)
- 라이트 / 다크 테마, 375px 모바일 대응
- 50회 누를 때마다 전면광고 (AdSense H5 Games Ads)

## 구조

`index.html` 한 파일이 전부입니다. 빌드 도구·의존성·백엔드가 없어서 그대로 정적 호스팅에 올리면 됩니다. 외부 요청은 Google Fonts와 광고 SDK뿐입니다.

## 광고 설정

기본 상태에서는 광고 SDK가 주석 처리되어 있고, 대신 개발용 플레이스홀더 모달이 뜹니다. 실제 광고를 붙이려면:

1. AdSense 승인을 받고 **H5 Games Ads**를 활성화합니다 (기본은 꺼져 있습니다)
2. `index.html` 상단의 `<script>` 주석을 풀고 `ca-pub-XXXXXXXXXXXXXXXX`를 실제 게시자 ID로 교체합니다
3. 도메인 루트에 `ads.txt`를 배치합니다
4. **HTTPS로 배포합니다** — `file://`에서는 광고 SDK가 동작하지 않습니다

### 알아둘 점

- **50회마다 항상 광고가 뜨지는 않습니다.** Google이 `frequencyCapped`, `noAdPreloaded` 등을 돌려주는 경우가 흔합니다. `adBreakDone`에서 상태를 받아 광고가 안 떠도 앱이 멈추지 않도록 처리되어 있고, 콘솔에 `[ad] breakStatus =` 로 찍힙니다.
- AdSense는 광고 시청을 유도하거나 보상하는 문구를 금지합니다. 관련 UI 카피를 추가하지 마세요.

## 커스터마이징

| 대상 | 위치 |
| --- | --- |
| 광고 주기 | `AD_INTERVAL` 상수 (기본 50) |
| 광고 네트워크 교체 | `triggerAd()` 함수 하나만 수정 |
| 콤보 유지 시간 | `COMBO_RESET_MS` (기본 1200ms) |
| 음계 | `SCALE` 배열 (C 메이저 펜타토닉) |
| 색상 | `:root` 의 CSS 변수 |

## 로컬에서 열기

`index.html`을 브라우저로 열면 바로 동작합니다. 콘솔에서 날짜 계산 함수를 직접 호출할 수 있습니다:

```js
__army.calcService('2026-03-02', '2027-09-01', new Date(2026, 8, 1))
```
