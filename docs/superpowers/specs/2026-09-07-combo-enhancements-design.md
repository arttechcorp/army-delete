# 콤보 이펙트 강화 및 복무 게이지 서지 상세 설계서

> **개요**  
> 본 문서는 '군생활 삭제 버튼'의 연타 만족감(Game Feel)과 도파민을 극대화하기 위한 콤보 시스템 2차 확장 설계서입니다.  
> 삭제 버튼 외 주변 UI 요소로 확산되는 단계별 화면 흔들림(Shake), 연타 시 복무율이 폭발적으로 상승했다가 원복되는 게이지 서지(Gauge Surge), 그리고 콤보 유지 시 층층이 두꺼워지는 Web Audio 실시간 레이어링을 규정합니다.

---

## 1. 핵심 설계 목표

1. **시각적 공간 확장 (UI 전파 흔들림)**
   - 단순 버튼 중심의 연출을 넘어, 연타가 지속될수록 상단 복무 현황 카드와 하단 지갑/상점 영역까지 타격 충격파가 단계적으로 퍼져나갑니다.
2. **목표 지향적 쾌감 (복무율 게이지 폭주 & 복귀)**
   - 콤보가 쌓일 때 복무율 프로그레스 바가 순간적으로 100%를 향해 전진하여 '전역이 눈앞으로 다가오는 환각'을 제공하고, 콤보 종료 시 원래 자리로 우아하게 글라이딩 복귀합니다.
3. **청각적 밀도 상승 (실시간 사운드 레이어링)**
   - 단음 위주의 멜로디에서 콤보 티어에 따라 화음(하모니), 서브 베이스(808 펄스), 고음 신스 차임(Shimmer)이 누적되어 음악적 클라이맥스를 연출합니다.
4. **경량화 및 무결성 유지**
   - 외부 라이브러리 없이 순수 HTML5 / CSS3 / Web Audio API만으로 구현하며, 저사양 및 모바일 환경에서도 60fps를 유지합니다.

---

## 2. UI 흔들림 (Screen & Element Shake) 단계별 확산

콤보 수치에 따라 흔들림의 진폭(Amplitude)과 전파되는 UI 대상 범위가 점진적으로 확대됩니다.

### 단계별 흔들림 매트릭스

| 콤보 단계 | 명칭 | 대상 UI 컴포넌트 | CSS 클래스 | 진폭 및 애니메이션 | 체감 효과 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Tier 1** (10~24) | Micro Shake | `.console` (버튼 및 플레이트) | `.shake-t1` | `±2px`, 0.12s, 1회 | 버튼 주변에 힘이 응축되는 긴장감 |
| **Tier 2** (25~49) | Mid Shake | `.console`, `.wallet`, `.enter-row` | `.shake-t2` | `±4px`, 0.15s, 1회 | 하단 지갑과 상점 메뉴로 충격 전파 |
| **Tier 3** (50~99) | Heavy Surge | 상단 `.card#result`, `.console`, `.wallet` | `.shake-t3` | `±6px`, 0.18s, 1회 | 상단 복무 카드까지 강타당하는 피버감 |
| **Tier 4** (100+) | Quake Singularity | `.wrap` (전체 화면 컨테이너) | `.shake-t4` | `±9px`, 0.25s + 백색 플래시 | 화면 전체가 붕괴하는 듯한 초월적 타격감 |

### 세부 동작 규칙
- **리플로우 강제**: 이전 애니메이션이 끝나기 전 빠른 연타가 들어올 경우 `void element.offsetWidth;`를 통해 애니메이션을 즉시 재시작합니다.
- **모션 감소(Accessibility)**: `prefers-reduced-motion: reduce` 설정 시 흔들림 애니메이션은 생략하고 테두리/오라 글로우(Glow) 효과로만 대체합니다.

## 3. 복무 진행상황 프로그레스 바 콤보 서지(Surge) 시스템

### 3.1. 동작 메커니즘
- **기준값(`basePct`)**: 사용자가 입력한 입대일/전역일 기준 실제 복무 진행률 (미입력 시 0%).
- **서지율(`surgePct`) 계산식**:
  $$\text{surgePct} = \min\left(100, \text{basePct} + (100 - \text{basePct}) \times \frac{\text{combo}}{100}\right)$$
  *(단, 입대 전이거나 미입력 상태여도 콤보에 비례하여 0%에서 최대 100%까지 채워짐)*
- **실시간 반응**:
  - 콤보가 증가할 때마다 프로그레스 바 너비(`barFill.style.width`)와 텍스트 숫자(`pctNum.textContent`)가 실시간으로 상승합니다.
  - 서지 동작 중에는 게이지 반응 속도를 높이기 위해 빠른 트랜지션(`transition: width 0.15s ease-out;`)을 적용합니다.

### 3.2. 콤보 티어별 게이지 비주얼 스타일
- **일반 (1~9 콤보)**: 기본 테마 컬러
- **Tier 1 (10~24 콤보)**: 에너지가 차오르는 옐로우 앰버 (`#facc15`)
- **Tier 2 (25~49 콤보)**: 네온 바이올렛 펄스 (`#c084fc`) + 미세 네온 글로우
- **Tier 3 (50~99 콤보)**: 피버 오렌지-골드 그라데이션 + 진행 바 외곽선 발광
- **Tier 4 (100+ 콤보)**: 하이퍼 무지개 오로라 그라데이션 애니메이션

### 3.3. 콤보 종료 시 원복 글라이딩 (Gliding Reset)
- 연타 중단 후 `COMBO_RESET_MS(1,400ms)`가 만료되면 콤보가 리셋됩니다.
- 리셋 타이머 동작 시:
  1. 프로그레스 바의 서지 스타일을 해제합니다.
  2. 부드러운 감속 이징(`transition: width 0.8s cubic-bezier(0.22, 1, 0.36, 1);`)을 활성화합니다.
  3. 실제 본래 복무율(`basePct`) 및 원래 숫자 텍스트로 우아하게 원복됩니다.

## 4. Web Audio 실시간 사운드 레이어링 아키텍처

1회성 마일스톤 폭발음(벨, 서브킥, 팡파르, 글리산도) 외에, **콤보를 이어가는 매 타격 클릭음 자체에 레이어가 층층이 덧입혀집니다.**

### 4.1. 사운드 레이어 구조

```
[Layer 0: 기본 타격]
  └─ thud() (노이즈 밴드패스 펀치) + tone() (펜타토닉 음계 사다리)

[Layer 1: 하모니 화음 (10 콤보+)]
  └─ tone(now, SCALE[comboIdx] * 1.25, gain: 0.12, dur: 0.14) (장3도 듀엣)

[Layer 2: 서브 베이스 펄스 (25 콤보+)]
  └─ soundLayerSubKick(now, gain: 0.28) (85Hz → 38Hz 급강하 808 펀치)

[Layer 3: 신스 차임 & 아르페지오 (50 콤보+ 피버)]
  └─ soundLayerShimmer(now) (옥타브 고음 삼각파 + 12ms 딜레이 고주파 차임)

[Layer 4: 하이퍼 오버드라이브 (100 콤보+ 초월)]
  └─ soundLayerSaw(now) (풍성한 톱니파 배음 + C5/G5 파워 코드 보강)
```

### 4.2. 음원 제어 및 리소스 관리
- **Voice Clamping**: 다층 레이어 사운드가 동시에 생성되므로, 연타 시 오디오 노드 폭주를 방지하기 위해 `track()` 관리 큐(`MAX_VOICES`)를 기존 8개에서 16개로 확장합니다.
- **모바일 사파리 호환**: 모든 레이어드 오디오 노드는 `Math.max(ctx.currentTime, 0.001)`로 시작 시간을 정렬하여 iOS 오디오 렌더링 지연에 따른 소리 끊김을 차단합니다.
- **즉각적 단음 리셋**: 콤보가 리셋되면 사운드 레이어 변수가 0으로 즉시 초기화되어, 다음 클릭 시 청명한 1단계 단음부터 다시 시작됩니다.

## 5. 검증 및 테스트 계획

1. **구문 및 정적 분석**
   - `node --check`로 인라인 스크립트 ES5 문법 및 런타임 무결성 검증
2. **자동화 테스트 (`scripts/test-analytics.js`)**
   - 신규 CSS 클래스(`.shake-t1` ~ `.shake-t4`, `.bar-surge` 등) 존재 검증
   - 신규 사운드 레이어 함수 및 콤보 서지 게이지 로직 정규식 검증
   - 기존 분석 이벤트 및 로직 100% 정상 통과 유지
3. **브라우저 및 디바이스 체감 검증**
   - 데스크톱/모바일 환경에서 10 -> 25 -> 50 -> 100 콤보 달성 시 UI 흔들림 영역 확장 확인
   - 연타 시 복무 진행 바가 100%로 시원하게 차오르는지 확인
   - 연타 중단 1.4초 후 원래 복무율로 부드럽게 글라이딩 복귀하는지 확인
   - iOS 사파리 환경에서 레이어 사운드 및 햅틱 정상 출력 확인
