# 상점 아이템

군생활을 빨리 보내고 싶은 현역 병사가 주 타겟이다. 버튼을 직접 누르다가 생활관에 병사를 모으고, 같이 냉동을 먹으며 군생활을 삭제한다. 번 일수로 휴가를 모으는 것이 성장 이후의 소비 목표다.

**상점 개편 구현 기준.** 2026-09-07 로컬 구현에 반영했다. 가격·능력치는 초기 밸런스이며 실사용자 플레이 테스트 전이다. 병사 6종은 SVG와 CSS 애니메이션으로 제작했다. 구현·검증 결과와 화면 캡처는 [구현 계획의 결과 기록](shop-implementation-plan.md#7-구현-검증-결과)에 남긴다.

## 장소별 역할

재화는 **일(삭제한 군생활)**이다. 상점에서는 `보유 일수`, 성장 기록에서는 `누적 삭제 일수`, 행정반에서는 `누적 휴가 일수`를 보여준다. 휴가는 별도 기록이며 실제 전역일이나 복무율을 바꾸지 않는다.

| 장소 | 한 줄 카피 | 얻는 것 | 구매 후 달라지는 것 |
| --- | --- | --- | --- |
| 생활관 | 신병 왔습니다! | 자동으로 버튼을 누르는 병사 | 함께 누르는 병사 수와 자동 획득량 |
| 체단실 | 한 세트만 더 하고 씻자. | 내 클릭 강화 | 내가 한 번 누를 때 삭제하는 일수 |
| P.X | 냉동 돌릴 건데 같이 먹을 사람? | 병사에게 보급할 음식 | 병사들의 1회 삭제량과 누르는 속도 |
| 행정반 | 그래서 휴가 며칠 남았습니까? | 연가·포상휴가·위로휴가 | 종류별 휴가 기록과 누적 휴가 일수 |
| 위병소 | 나갈 때가 제일 빠르다. | 일수 선물·공유·면회·외박 기념품 | 동기에게 일수 보내기와 수집 기록 |

칩 순서는 **생활관 → 체단실 → P.X → 행정반 → 위병소**로 한다. 기존 연병장 칩은 체단실로 교체한다. 작업·제설·예초를 또 다른 자동 생산 상점으로 운영하지 않고, 추후 일과 이벤트 소재로 남긴다.

성장 흐름은 `직접 눌러 일수 모으기 → 병사 충원 → 체단실에서 내 클릭 강화 / P.X에서 병사 강화 → 휴가 모으기`다. 상위 아이템을 사도 먼저 산 병사와 강화 효과가 계속 유효해야 한다.

## 말투와 단어

게시글의 짧은 생활어와 드라마의 캐릭터별 말투를 참고한다. 전원이 다나까를 쓰거나 모든 설명이 군대 명언처럼 끝나지 않게 한다. 아래 아이템 설명과 캐릭터 대사는 이 게임을 위해 새로 쓴 문구다. 참고 자료는 문서 끝에 둔다.

| 쓰는 자리 | 방향 | 게임 문구 예시 |
| --- | --- | --- |
| 막 전입한 이병 | 짧은 보고체, 대답부터 나오는 긴장감 | “이거 누르면 됩니까?” / “누르겠습니다!” |
| 일병·상병 | 일과에 익숙한 생활어, 슬슬 나오는 투덜거림 | “이거 끝나고 피엑스 가실 분?” / “오케이, 내가 할게.” |
| 병장·말년 | 말수가 줄고, 휴가와 집 얘기가 먼저 나옴 | “어, 눌렀어.” / “나 말출 전까지만 한다.” |
| 아이템 설명 | 물건을 보고 실제로 할 법한 한마디 | “전자레인지 누가 쓰냐. 나 다음.” |
| 버튼·효과·잔액 안내 | 행동과 수치를 바로 알 수 있는 문장 | `충원하기` / `내 클릭 +2일` / `150일 부족` |

주요 어휘는 **신병, 전입, 동기, 선임, 후임, 짬, 말년, 말출, 개인정비, 점호, 체단실, 냉동, 피엑스, 휴가증**이다. `말출`은 첫 등장에 `말출(말년휴가)`로 풀어 쓴다. 장소명은 `P.X`, 대화에서는 `피엑스`로 구분한다.

욕설을 넣는 것 자체를 현실감으로 삼지 않는다. 웃음은 점호 전 냉동 돌리기, 운동 한 세트 더 하기, 휴가 날짜 세기 같은 상황에서 만든다. 군별·부대별로 다른 표현을 전군 공통이라고 단정하지 않으며, 육군 생활관에 가까운 현재 배경을 기준으로 쓴다.

## 생활관 — 병사 충원

> 신병 왔습니다!

병사를 충원하면 메인 버튼 옆에 실제 캐릭터가 합류해 자동으로 누른다. 행동명은 `충원하기`, 완료 상태는 `함께 복무 중`이다. 병사마다 1회만 충원하며 모두 동시에 일한다. 계급이 같아도 별개의 캐릭터이고, 새 병사를 충원한다고 기존 병사가 진급하거나 사라지지 않는다.

모든 병사의 기본 1회 삭제량은 **1일**이다. 차이는 기본 클릭 간격과 동작에서 시작하고 P.X 음식으로 전체 병사의 능력치가 오른다. 실제 사용자의 계급이나 복무율로 충원을 막지 않는다.

| 이름 | 가격 | 기본 자동 클릭 | 성격·한 줄 대사 | 외형·소품 |
| --- | --- | --- | --- | --- |
| **신병 이병** | 200일 | 약 13.3초마다 1회 | 뭐든 힘이 들어간 신병. “이거 누르면 됩니까?” | 각 잡힌 전투복, 큰 눈, 옆에 놓인 더블백 |
| **일잘알 일병** | 500일 | 약 6.7초마다 1회 | 다음 할 일까지 계산한다. “이거 끝나고 피엑스 가실 분?” | 걷은 소매, 손목시계 |
| **체단실 상병** | 800일 | 약 4.4초마다 1회 | 개인정비는 곧 운동 시간. “이것도 전완근 먹네.” | 체육복, 목에 걸친 수건 |
| **분대장 상병** | 1,200일 | 약 3.3초마다 1회 | 인원도 버튼도 빠짐없이 챙긴다. “다 왔지? 누르고 쉬자.” | 분대장 견장, 작은 수첩 |
| **누워 있는 병장** | 1,800일 | 약 2.2초마다 1회 | 움직임은 작고 손은 정확하다. “어, 눌렀어.” | 생활복, 슬리퍼, 접은 모포 |
| **말출 앞둔 병장** | 3,000일 | 약 1.1초마다 1회 | 집 갈 생각에 손만 바쁘다. “나 말출 전까지만 한다.” | 달력, 반쯤 싸둔 더블백 |

하사·중사·상사는 병사가 아니므로 신규 생활관 충원 목록에서 제외한다. 간부를 쓴다면 이후 일과 이벤트의 등장인물로 분리한다. 말년 캐릭터의 ‘쉬는 자세’는 외형일 뿐 자동 생산이 임의로 중단되지는 않는다.

### 병사가 직접 버튼을 누르는 디자인

**계급장만 반짝이는 현재 표현을, 몸을 움직여 버튼에 손이 닿는 장면으로 바꾼다.** 2~3등신의 단순한 병사 일러스트로 통일하고 얼굴·자세·소품으로 구분한다. 특정 배우의 얼굴이나 드라마 캐릭터 의상을 복제하지 않는다.

| 병사 | 대기 → 준비 → 접촉 → 복귀 | 접촉 이펙트 |
| --- | --- | --- |
| 신병 이병 | 차렷 → 양손을 모아 들어 올림 → 두 손으로 꾹 → 다시 차렷 | 작은 땀방울 하나, 반듯한 눌림선 |
| 일잘알 일병 | 시계 확인 → 손목만 돌림 → 검지로 톡 → 시계 확인 | 짧고 얇은 잔상 한 줄 |
| 체단실 상병 | 어깨 풀기 → 팔을 접음 → 손바닥으로 꾹 → 팔 털기 | 접촉점의 굵은 충격선 두 개 |
| 분대장 상병 | 수첩 확인 → 손을 뻗음 → 정확히 한 번 → 수첩에 체크 | 작은 체크 표시가 뜸 |
| 누워 있는 병장 | 모포에 기대기 → 팔만 늘어뜨림 → 손가락으로 툭 → 같은 자세 | 힘 빠진 짧은 눌림선 |
| 말출 앞둔 병장 | 달력 보기 → 시선은 둔 채 손만 뻗음 → 재빠르게 탁 → 날짜 확인 | 달력 낱장 하나가 들썩임 |

모두 **하나의 메인 삭제 버튼 가장자리**를 누른다. 별도 장식 버튼을 누르거나 캐릭터는 가만히 있는데 중앙 버튼만 빛나는 방식은 피한다. 손과 버튼의 접촉점이 연결되어야 누가 벌었는지 보인다.

모바일 구성 예시(완성 시안이 아닌 배치 명세, 수치는 예시):
```text
보유 1,250일                     누적 휴가 9일
        이병      일병      상병
          ↘        ↓        ↙
              [ 삭제 버튼 ]
          ↗        ↑        ↖
       분대장     병장      말년
내 클릭 4일/회       병사 자동 약 2.0일/초
생활관 · 체단실 · P.X · 행정반 · 위병소
```

- 375px 화면에서는 버튼 위·아래에 병사 3명씩, 넓은 화면에서는 버튼 좌우에 3명씩 배치한다. 캐릭터 영역은 미리 확보해 충원 시 버튼 위치가 밀리지 않게 한다.
- 본체 그림은 40~56px 기준으로 단순화하고, 눌러 정보를 보는 영역은 최소 44×44px로 둔다. 캐릭터가 버튼 중앙의 터치 영역을 가리지 않게 한다.
- 개별 동작은 300~450ms 안에 끝낸다. 실제 지급 시점이 손의 접촉 시점과 맞고 `+N일`은 해당 접촉점 근처에서 뜬다. 자동 클릭은 소리·진동·사용자 연타 콤보를 발생시키지 않는다.
- 동시 접촉은 최대 2명까지 보여주고 겹치는 연출은 생략하거나 합산 표시한다. 화면 연출 때문에 지급을 늦추거나 누락하지 않는다. 빨라진 자동 클릭을 하나하나 재생하느라 동작이 끊기지 않게 한다.
- 대사는 합류할 때와 캐릭터를 눌렀을 때 짧게 표시한다. 매 자동 클릭마다 말풍선을 띄우지 않는다. 병사 상세에는 이름, 현재 `일/회`, `초마다 1회`, 음식 강화 내역을 보여준다.
- P.X 구매 시 음식이 병사 쪽으로 전달되는 짧은 연출과 `전체 병사 1회 삭제량 +1일` 같은 결과를 보여준다. 이후 충원한 병사에도 같은 강화가 적용된다.
- `동작 줄이기` 설정과 `prefers-reduced-motion`에서는 팔 이동·잔상·충격선을 끄고 고정 캐릭터와 숫자로 결과를 전달한다. 대기 중에는 반복적으로 흔들거나 뛰지 않는다. 색상 외에 이름과 소품으로도 구별한다.

제작할 에셋은 **병사 6종의 대기·준비·접촉·복귀 포즈, 각 병사 소품, 공통 버튼 눌림, 접촉선·체크·음식 전달 이펙트**다. 먼저 이병과 누워 있는 병장으로 자세 차이와 손의 접촉이 잘 보이는지 검증한 뒤 나머지 4종을 제작한다.

## 체단실 — 내 클릭 강화

> 한 세트만 더 하고 씻자.

내가 버튼을 한 번 누를 때 삭제하는 일수를 올린다. 기본은 **1일/회**이며 산 운동의 추가 일수를 전부 더한다. 병사의 자동 클릭에는 적용하지 않는다. 각 운동은 1회 구매하는 영구 강화이며 표시한 가격만 충족하면 구매할 수 있다.

| 이름 | 가격 | 효과 | 설명 |
| --- | --- | --- | --- |
| **팔굽혀펴기부터** | 150일 | 내 클릭 +1일 | “정자세로 열 개만. 일단 열 개만.” |
| **덤벨 한 세트** | 500일 | 내 클릭 +2일 | “이거 쓰십니까? 안 쓰시면 제가 좀.” |
| **벤치 보조 좀** | 1,500일 | 내 클릭 +4일 | “안 들었어. 너 혼자 든 거야.” |
| **오늘 하체하는 날** | 4,000일 | 내 클릭 +8일 | “내일 계단은 내일 생각하자.” |

예: 기본 1일 + 팔굽혀펴기 1일 + 덤벨 2일 = **직접 클릭 4일/회**. 전부 사면 16일/회다. 구매 카드에는 `내 클릭 2 → 4일/회`처럼 현재 수치와 결과를 표시한다. 버튼 아래 수치는 즉시 바뀌고, 직접 누를 때 버튼 압축과 접촉선이 강화되어 운동 효과가 보인다.

## P.X — 먹이고 병사 강화

> 냉동 돌릴 건데 같이 먹을 사람?

음식을 사면 **현재·이후 충원하는 모든 병사**의 능력치가 오른다. 능력치는 `1회 삭제량`과 `자동 클릭 속도` 두 가지다. 체단실에서 올리는 내 클릭 수치와는 별도로 계산한다.

첫 버전에서는 음식마다 1회 구매하는 **상시 보급 해금**으로 정한다. 구매 후 상태는 `보급 중`이며 배고픔 게이지나 지속시간·재급식은 없다. 병사가 없을 때도 살 수 있지만 `충원 후 적용 · 현재 병사 0명`을 구매 전에 명시한다.

| 이름 | 가격 | 전체 병사 효과 | 설명 |
| --- | --- | --- | --- |
| **초코파이 한 상자** | 50일 | 1회 삭제량 +1일 | “하나씩 가져가. 내 것도 남겨 놓고.” |
| **냉동 피자** | 300일 | 자동 클릭 속도 +10%p | “전자레인지 누가 쓰냐. 나 다음.” |
| **냉동 치킨** | 800일 | 1회 삭제량 +2일 | “가운데 아직 차갑다. 좀 더 돌려.” |
| **공화춘 + 간짬뽕** | 1,500일 | 자동 클릭 속도 +20%p | “물 다 버리지 마. 섞어야 돼.” |
| **냉동 풀코스** | 3,000일 | 1회 삭제량 +4일 | “오늘 월급 들어왔다. 먹고 싶은 거 골라.” |

삭제량 추가치는 합산한다. 속도는 기본 100%에 추가 %p를 합산한다. 냉동 피자와 공화춘 조합을 모두 사면 **속도 130%**, 실제 클릭 간격은 `기본 간격 ÷ 1.3`이다. ‘간격 30% 감소’와 혼동하지 않게 한다.

예: 초코파이 구매 후 병사마다 **2일/회**가 된다. 신병 이병의 기본 간격을 13.3초로 보면 속도 130%에서 약 **10.2초마다 2일**을 번다. 내 직접 클릭 수치는 그대로다. 모든 음식을 사면 병사마다 8일/회, 속도 130%가 된다.

구매 카드에는 `전체 병사 1 → 2일/회`, `자동 속도 110 → 130%`처럼 바뀌는 능력치를 표시한다. 가장 비싼 음식만 적용하는 배수 사다리는 폐기한다.

## 행정반 — 휴가 구매와 누적

> 그래서 휴가 며칠 남았습니까?

삭제해서 모은 **보유 일수**로 휴가를 구매한다. 연가·포상휴가·위로휴가는 모두 **정해진 일수가 확정 지급**되고 횟수 제한 없이 다시 구매할 수 있다. 첫 버전의 휴가는 아래 게임 수치로 정하며 실제 군 휴가의 지급 기준을 재현하지 않는다.

| 이름 | 가격 | 구매 효과 | 설명 |
| --- | --- | --- | --- |
| **연가 1일** | 1,000일 | 연가 +1일, 누적 휴가 +1일 | “하루만 붙이면 주말까지 나갑니다.” |
| **포상휴가 3일** | 2,800일 | 포상휴가 +3일, 누적 휴가 +3일 | “이거 휴가 나오는 거 맞죠?” |
| **위로휴가 5일** | 4,500일 | 위로휴가 +5일, 누적 휴가 +5일 | “고생했다는 말보다 이게 좋습니다.” |

구매 버튼은 `1,000일로 구매`처럼 비용을 명확히 쓴다. 성공하면 휴가증에 도장이 찍히고 `연가 +1일 · 누적 휴가 9일`을 표시한다. 잔액 부족이면 차감·지급 모두 하지 않는다.

행정반 상단에는 **누적 휴가 9일**과 `연가 1일 · 포상휴가 3일 · 위로휴가 5일`을 함께 보여준다. 메인 화면에도 누적 휴가 합계를 작게 표시해 상점을 닫아도 목표가 남는다.

### 휴가 회계

- `누적 휴가 일수 = 누적 연가 + 누적 포상휴가 + 누적 위로휴가`다. 종류별 누적값으로 합계를 계산하며 서로 다른 숫자가 저장되어 어긋나지 않게 한다.
- 구매 시 보유 일수에서 가격만 차감한다. **누적 삭제 일수는 줄지 않으며 휴가 지급으로 삭제 일수나 재화가 늘지도 않는다.**
- 예: 잔액 5,000일 / 누적 삭제 7,000일 / 누적 휴가 0일에서 포상휴가를 사면 잔액 **2,200일** / 누적 삭제 **7,000일** / 누적 휴가 **3일**이다.
- 휴가는 소비·환전·배수 효과가 없는 수집 목표다. 현재 기획에는 휴가 사용 기능이 없으므로 `남은 휴가` 대신 `누적 휴가`라고 표시한다.
- 새로고침과 계정 복원 후에도 종류별 누적값을 유지해야 한다. 재구매 횟수는 기존의 단순 보유 목록만으로 표현할 수 없으므로 별도 누적 기록이 필요하다.
- 기존 **포상휴가 룰렛은 신규 판매에서 제외**한다. 휴가 구매에 꽝이나 삭제 일수 환급을 섞지 않는다.

## 위병소 — 일수 선물·공유·기념품

> 나갈 때가 제일 빠르다.

현재 일수 선물·공유·수집 기능을 위병소에 모은다. **메인 화면의 별도 ‘일수 선물하기’ 버튼은 위병소 안으로 옮긴다.** 위병소에서 병사를 충원하거나 누적 휴가를 얻지는 않는다. 효과 없는 기념품에는 구매 전 `수집용 · 능력치 변화 없음`을 표시한다.

| 이름 | 가격 | 효과 | 설명 |
| --- | --- | --- | --- |
| **일수 선물하기** | 보낼 일수 직접 입력 | 보유 일수를 편지와 함께 전달, 반복 이용 | “너도 며칠 가져가. 같이 전역하자.” |
| **소문내기** | 무료 | 공유 성공 후 30분간 직접·자동 획득량 ×3 | “야, 이거 누르고 있으면 시간은 간다.” |
| **훈련소 동기** | 200일 | 동기 사진 기념품, 1회 구매 | “야, 너 자대 어디 갔냐?” |
| **면회** | 400일 | 면회 사진 기념품, 1회 구매 | “올 때 햄버거 좀. 아니, 두 개.” |
| **외박증** | 900일 | 외박증 기념품, 1회 구매 | “밖에 나왔는데 왜 여섯 시에 깨냐.” |

### 일수 선물하기 동선

위병소 상단에 `일수 선물하기` 행동 카드를 배치한다. 정가 상품이나 무료 재화 지급으로 취급하지 않고, 보낼 일수를 기존 보유 잔액에서 차감한다. `전체` 목록과 `선물` 검색에서도 이 카드를 찾을 수 있다.

`상점 → 위병소 → 일수 선물하기 → 일수 입력 → 편지 작성 → 링크 만들기 → 공유·복사` 순서다. 기존 발신·수령 기능을 재사용한다. 선물 창을 열 때 상점은 닫고, 취소·닫기 시 위병소의 카드로 돌아온다. 두 모달을 겹쳐 띄우지 않는다.

발신은 기존처럼 로그인이 필요하며, 로그인 후에는 위병소의 선물 작성으로 돌아오게 한다. 링크로 들어온 수령자는 상점을 거치지 않고 바로 수령 화면을 열며 로그인 없이 받을 수 있다. 수령 화면을 닫으면 메인으로 돌아온다.

선물 링크가 생성된 뒤 공유·복사를 취소해도 선물이 생성 취소되거나 자동 환불되지는 않는다. 생성된 링크를 다시 확인할 수 있는 상태를 유지하고, 전송 중 재클릭은 막는다. 서버가 생성에 성공했을 때만 발신 일수를 차감하며 한 링크는 한 번만 수령된다. 선물에는 생산 배수나 누적 휴가 증가를 적용하지 않는다.

### 소문내기

공유창 완료 또는 링크 복사 성공을 보상 조건으로 삼는다. 현재 코드는 복사 실패에도 보상을 지급하므로 구현 시 고친다. 지속시간을 중복해서 더하지 않고 종료 후 다시 받을 수 있다. 상세 효과에는 `직접·자동 ×3 · 30분`을 표시하며 휴가 구매량·광고 보상·선물에는 적용하지 않는다.

## 효과 적용 규칙

| 항목 | 적용 방식 | 적용 대상 |
| --- | --- | --- |
| 생활관 병사 | 충원한 모든 병사가 각각 자동 클릭 | 자동 생산 |
| 체단실 운동 | 기본 1일 + 구매한 운동의 추가 일수 합계 | 내 직접 클릭 |
| P.X 삭제량 | 기본 1일 + 구매한 음식의 추가 일수 합계 | 병사 각각의 자동 클릭 |
| P.X 속도 | 기본 간격 ÷ (1 + 속도 추가 %p 합계 / 100) | 병사 각각의 자동 클릭 간격 |
| 위병소 공유 | 위에서 계산한 직접·자동 1회 획득량에 마지막으로 ×3 | 활성화된 30분 동안의 생산 |
| 위병소 선물 | 보낸 일수만큼 잔액과 순누적에서 차감, 수령 시 받은 일수에 가산 | 기존 선물 회계, 휴가는 변하지 않음 |
| 행정반 휴가 | 구매한 휴가 종류에 확정 일수 합산 | 누적 휴가 기록만 |

**‘배수·짬·공유 중 가장 높은 하나만 적용’하는 기존 규칙은 개편안에서 사용하지 않는다.** 직접 클릭 성장과 병사 성장은 별개로 누적되고 공유는 두 성장 결과에 일시적으로 곱한다. 짬의 복무율 배수는 신규 구매 효과에서 제외한다.

지급하는 일수와 누적 휴가는 정수로 유지한다. 클릭 간격과 화면의 `일/초` 표시는 소수가 될 수 있지만, 초당 표시값을 매번 내림해서 실제 지급량으로 사용하지 않는다. 병사의 실제 클릭 횟수에 정수 1회 삭제량을 곱해 지급한다.

## 기존 아이템 정리와 구현 범위

이 문서 변경만으로 기존 구매 기록이나 앱 기능은 바뀌지 않는다. 신규 구성을 앱에 적용할 때는 기존 보유 ID를 보존하고 아래 전환을 함께 구현해야 한다. 구현 계획의 기본안은 **기존 구매 효과 보존**이다. 위 성장 공식은 신규 구성 기준이며, 구보유자는 구배수를 최소 생산량으로 인정하는 호환 규칙을 적용한다.

| 기존 구성 | 개편 방향 |
| --- | --- |
| 이병·일병·상병·병장 | 기존 ID를 유지하고 새 이름·외형을 적용. 가격·간격 조정은 실제 전환 시 검증 |
| 하사·중사·상사 | 신규 충원 목록에서 제외. 구간격·구배수 생산을 ‘이전 부대 지원’으로 보존하며 신규 음식 강화는 미적용 |
| 모포 각 잡기·지니티비 | 신규 성장 목록에서 제외. 보유 기록 유지, 지니티비 구배수도 보존. 배경 소품 활용 가능 |
| 짬 | 신규 판매 제외. 기존 보유자의 복무율 배수를 최소 생산량 계산에 사용 |
| 작업 나가기·제설작전·예초 작업·완전군장 구보 | 연병장 신규 판매 제외. 구배수·구자동 생산 보존, 일과 이벤트 재사용은 후속 범위 |
| 초코파이·냉동 피자·맛다시 계란·박카스 | 구ID와 구효과 보존. 의미가 달라지는 신규 음식 강화에는 새 ID를 사용 |
| 포상휴가 룰렛·위로휴가 일주일 | 룰렛 신규 판매 제외, 과거 당첨금 재지급 없음. 위로휴가 구보유분은 중복 방지 이관으로 7일 인정 |
| 병장 진급 명령지·조기 전역·전역증 | 기존 보유품은 기념품 기록에 유지. 신규 행정반은 휴가 3종에 집중 |
| 국방부 시계 | 기존 보유자의 최대 8시간 오프라인 기능 보존. 신규 판매 위치는 미정이며 휴가 목록에 섞지 않음 |
| 소문내기·훈련소 동기·면회·외박증 | 위병소에 유지. 공유의 배수 적용 순서만 새 규칙과 정합성을 맞춤 |
| 메인 일수 선물하기 버튼 | 위병소 행동 카드로 이동. 기존 링크·발신·비로그인 수령 기능 유지 |

상점 데이터·장소 필터, 직접/자동 획득량, 병사 연출, 휴가 재구매·저장·계정 동기화를 함께 구현했다. 개인정보처리방침에도 추가 저장 항목을 반영했다. 기존 ID는 판매 목록과 판매 종료 정의를 합쳐 보존하며, 구효과와 새효과의 병합 규칙은 계산 모듈에서 처리한다.

### 구현 후 확인할 장면

- 이병을 충원하면 캐릭터가 합류하고 손이 버튼에 닿을 때 1일이 지급된다. 여러 명을 충원하면 기존 병사도 계속 누른다.
- 팔굽혀펴기를 사면 내 클릭만 1 → 2일이 되고 병사 클릭은 1일로 유지된다.
- 초코파이를 사면 모든 병사 클릭이 1 → 2일이 된다. 이후 충원한 병사에도 적용되며 내 클릭은 변하지 않는다.
- 속도 음식 두 개를 사면 속도 130%, 간격은 기본의 약 76.9%가 된다. 먼저 산 음식도 계속 유효하다.
- 휴가를 연속 구매하면 매번 비용과 휴가가 한 번씩 반영된다. 잔액 부족·새로고침·다른 탭 변경·계정 복원에서도 합계가 맞는다.
- 공유 보상이 켜지고 꺼질 때 직접·자동 생산만 ×3이 적용·해제된다. 구매한 휴가 일수에는 배수가 붙지 않는다.
- 위병소에서 선물 창을 열고 닫으면 위병소로 돌아온다. 로그인 후 작성 복귀와 외부 선물 링크의 직접 수령이 모두 동작한다.
- 375px 화면에서 여섯 병사의 동작을 구분하고 중앙 버튼을 누를 수 있다. 동작 줄이기 상태에서도 능력치와 지급 결과를 확인할 수 있다.
